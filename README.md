# Письмо для Баясаны

Небольшой адаптивный сайт-письмо. Все изображения уже лежат в папке `assets`.

## Как открыть локально
Откройте `index.html` в браузере.

## Как загрузить в GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html`, папку `assets` и этот `README.md` (или загрузите содержимое ZIP-архива).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через минуту GitHub покажет ссылку на опубликованный сайт в разделе Pages.

Пароль для первого экрана: `donkey`.

Чтобы изменить тексты или пароль, откройте `index.html` и найдите нужную фразу. Пароль проверяется в JavaScript в строке `value === 'donkey'`.
